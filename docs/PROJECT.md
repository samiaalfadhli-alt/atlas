- لا يوجد نشر مباشر من المعلن — كل تعديل وإعلان وبنر جديد يدخل مركز الموافقات ولا يظهر إلا بعد اعتماد الإدارة (provisional)
- صاحب الموقع وSuper Admin ينشرون مباشرة إذا أرادوا (provisional)
- التكاملات الخارجية عبر APIs رسمية وOAuth فقط، والمفاتيح محفوظة في بيئة الخادم ولا تُعرض للواجهة (provisional)

## Decisions

- التسجيل يتطلب اختيار باقة إجباريًا؛ كل الباقات تمنح تجربة مجانية ٣٠ يومًا، وتُسجَّل حالة الاشتراك (trialing) وتواريخ التجربة على ملف الشركة دون محاكاة دفع
