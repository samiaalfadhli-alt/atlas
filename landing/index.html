WhatsApp Hub

لوحة واحدة لإدارة جميع أرقام ومنصات واتساب: صندوق وارد موحّد، ربط QR وCloud API، وسائط، ردود جاهزة وتلقائية.

هذه صفحة تعريفية فقط. التطبيق يحتاج خادم Node.js دائم (اتصال مستمر بواتساب + تخزين الجلسات) ولا يعمل على Vercel Serverless.

التشغيل على خادمك (VPS / Railway / Render)

cd whatsapp-hub
cp .env.example .env   # ضع ADMIN_PASSWORD
npm install
npm start              # http://localhost:3000

التشغيل الدائم

npm i -g pm2
pm2 start src/server.js --name whatsapp-hub

الكود الكامل في مجلد whatsapp-hub/ داخل المستودع.
